AFTER‑MINERU · EXPERIMENTAL

精准转换

扩展只在你明确选择文件并授权后直连 MinerU；Paper2MD 服务器不接收或保存 Token、PDF 或转换结果。

开始前请确认

  • 这个扩展只有一个用途：转换你明确选择的 PDF 并下载 MinerU 原始结果。
  • 文件名与 Token 发送到 mineru.net API；PDF 直传 MinerU 的阿里云 OSS 签名地址。
  • 转换完成后，扩展从 OpenXLab CDN 的签名地址下载结果 ZIP。
  • Token 只存在当前扩展页内存；刷新、关闭或任务结束即清除。
  • 三个 MinerU 域名权限仅为本次任务申请；任务结束后会尝试自动撤销，失败时会提示你手动撤销。
  • 下载 ZIP 通过结构与路径校验后仍保持 MinerU 原始结果不变。
  • “取消”只停止浏览器端传输并清除本页 Token；已上传文件或远端任务的处理与保留仍遵循 MinerU 政策，必要时请到 Token 管理页吊销 Token。
